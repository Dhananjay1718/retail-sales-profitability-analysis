# Data

Source: synthetic records generated by ../python/build_project.py, seed 42.
No external dataset, personal records, real transactions or scraped data.
Period: January–December 2025. Currency: INR. Grain: one single-product order.

| Field | Meaning |
|---|---|
| order_id | Unique synthetic order ID |
| order_date, month | Date and YYYY-MM period |
| customer_id | Synthetic customer key |
| region | Sales region; missing values become Unknown |
| product, category | Product attributes |
| quantity | Positive whole-number units |
| unit_price, unit_cost | INR per unit |
| discount | Fraction; 0.10 means 10% |
| shipping_cost | INR cost per order |
| gross_sales | quantity × unit_price |
| revenue | gross_sales × (1 − discount) |
| cost | quantity × unit_cost + shipping_cost |
| profit | revenue − cost |
| discount_band | None, Low (1-10%), High (>10%) |

orders_raw.csv contains controlled quality problems; orders_clean.csv is the
validated fact table. products.csv has a unique product key for the SQL JOIN.
Customer IDs can repeat; order IDs must not repeat after exact deduplication.
Unknown region is preserved to avoid losing financial totals.

The full-year generator is illustrative and does not model a real demand process.
Negative order profit is valid and is not removed as an outlier.
